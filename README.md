# مشروع تشغيل الفيديو

مشروع بسيط لعرض وتحديث الفيديو محلياً.

## ⚠️ ملاحظة هامة حول ملف الفيديو
ملف الفيديو كبير الحجم لذا لم يتم رفعه على Git / GitHub.

### متطلبات التشغيل:
1. قم بتحميل أو توفير ملف الفيديو الخاص بك.
2. تأكد من تسمية الملف بالاسم التالي بالضبط:
   `[Cimawbas].Sar5et.Namla.2011.mp4`
3. ضع ملف الفيديو في الفولدر الرئيسي للمشروع (بجوار ملف `index.html` أو كود التشغيل).
4. افتح الكود أو شغّل الصفحة وسيتم قراءة الفيديو مباشرة.
